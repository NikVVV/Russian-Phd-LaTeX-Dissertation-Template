\chapter*{Список сокращений}

\begin{description}

\item[СЛАУ]~--- Система линейных алгебраических уравнений.

\item[СУБД]~--- Система управления базами данных.

\item[ЭВМ]~--- Электронная вычислительная машина.

\item[ACM]~--- Обозначение реализации предложенной
адаптивной стоимостной модели.

\item[BAO] Bandit Optimizer~--- метод оптимизации запросов
на основе контекстного многорукого бандита.

\item[CEB] Cardinality Estimation Benchmark~--- набор тестов
для исследования методов оценки кардинальности
и оптимизации запросов.

\item[GELU] Gaussian Error Linear Unit~--- функция активации
нейронной сети.

\item[IMDb] Internet Movie Database~--- база данных
о кинофильмах.

\item[JOB] Join Order Benchmark~--- набор тестовых запросов
для исследования оптимизации порядка соединений.

\item[JSON] JavaScript Object Notation~--- текстовый формат
представления структурированных данных.

\item[NVMe] Non-Volatile Memory Express~--- протокол доступа
к энергонезависимым накопителям.

\item[OLAP] Online Analytical Processing~--- аналитическая
обработка данных.

\item[OLTP] Online Transaction Processing~--- транзакционная
обработка данных.

\item[PCA] Principal Component Analysis~--- метод главных
компонент.

\item[QLoRA]~--- Метод дообучения языковой модели
с использованием квантованных базовых весов
и обучаемых адаптеров малого ранга.

\item[QR]~--- Обозначение разложения матрицы в произведение
ортогональной и верхнетреугольной матриц.

\item[RL] Reinforcement Learning~--- обучение
с подкреплением.

\item[SQL] Structured Query Language~--- язык
структурированных запросов.

\item[SSD] Solid-State Drive~--- твердотельный накопитель.

\item[SVD] Singular Value Decomposition~--- сингулярное
разложение матрицы.

\item[TCNN] Tree Convolutional Neural Network~---
свёрточная нейронная сеть для обработки деревьев.

\item[TPC-H]~--- Набор тестов производительности систем
поддержки принятия решений, разработанный
Transaction Processing Performance Council.

\item[TS] Thompson Sampling~--- сэмплирование Томпсона.

\item[WMAE] Weighted Mean Absolute Error~--- взвешенная
средняя абсолютная ошибка.

\end{description}
